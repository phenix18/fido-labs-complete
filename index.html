🔧 Diagnostic & stratégie d'extraction (tous états)
Appareil non débogué, écran cassé, verrouillé ou éteint — méthodes légales SANS déverrouiller ni contourner le verrou.
🛰️ Acquisition d'image — appareil verrouillé / non débogable
Pour TOUT téléphone verrouillé, non débogué (adb unauthorized), écran cassé ou BFU : plan d'acquisition d'image forensique. Sources non protégées par le verrou (SIM, SD) d'abord, puis dump physique du chiffré (BROM/EDL) ou acquisition DFU checkm8 (iOS A5–A11). Aucun contournement du verrou : on acquiert l'image où elle est légalement accessible.
💾 Copie d'image d'un support amovible (SD / USB / lecteur SIM)
Acquisition forensique réelle (copie brute + SHA256 + manifeste chaîne de garde) d'un support retiré du téléphone verrouillé — indépendant du verrou.
🍎 Profil iOS & capacités checkm8
Identification du modèle iPhone/iPad (product_type) → chipset A-series → capacités d'extraction réelles, notamment la compatibilité checkm8 (acquisition DFU sur appareils A5–A11 verrouillés, Secure Enclave intacte).
⚡ Extraction physique MediaTek (BROM) — sans déverrouillage
Via mtkclient. Appareil éteint → mode BROM (maintenir Vol+ ou Vol- en branchant). Pilote USB requis (UsbDk/libusb). Le dump est chiffré (lisible seulement en état AFU). Aucun contournement du verrou.
⚡ Extraction physique Qualcomm (EDL 9008) — sans déverrouillage
Via edl (Sahara/Firehose). Appareil en mode EDL 9008 (câble EDL ou test point). Un loader firehose (.elf) spécifique au chipset est requis pour la plupart des appareils. Dump chiffré (lisible si AFU). Aucun contournement du verrou.
🔬 Analyse ALEAPP — rapport forensique complet
Parse une extraction Android (dossier, tar, zip) en rapport HTML professionnel : comptes, appels, SMS, apps, localisations, historiques, centaines d'artefacts.
🍎 Analyse sauvegarde iPhone (iTunes / Finder)
Analyse une sauvegarde iOS locale (dossier contenant Manifest.db) : SMS/iMessage, contacts, journal d'appels — chaque preuve scellée SHA256. Sauvegarde chiffrée → signalée, aucun contournement. Chemin type : %APPDATA%\Apple Computer\MobileSync\Backup\<UDID>
📲 Acquisition iPhone en direct (libimobiledevice)
Crée une sauvegarde directement depuis un iPhone/iPad branché, puis l'analyse. Prérequis : service Apple Mobile Device (app « Appareils Apple » du Microsoft Store ou iTunes) + toucher « Se fier à cet ordinateur » sur l'appareil. Sauvegarde autorisée — aucun contournement.
🗂️ Analyse sauvegarde Android (adb backup .ab)
Déballe un fichier .ab (format adb backup) : décompression zlib + extraction du tar, inventaire par application, bases SQLite détectées et hachées SHA256. Sauvegarde chiffrée → signalée (aucun contournement). Créer le .ab : adb backup -apk -shared -all -f sauvegarde.ab (confirmer sur l'appareil).

Forensique WhatsApp

Déchiffrement msgstore.db.crypt14/15 et analyse des échanges

💬 WhatsApp

🔐 Déchiffrer une sauvegarde WhatsApp (.crypt14 / .crypt15)
Déchiffre msgstore.db.crypt15 (ou crypt14) avec la clé WhatsApp fournie légalement — 64 caractères hexadécimaux (fichier « encrypted_backup.key » / « key »). AES-256-GCM, aucun contournement.
La récupération lit les zones non allouées (freeblocks) de n'importe quelle base SQLite — fonctionne aussi sur mmssms.db, contacts, etc.
#DateDeÀMessageTypeStatut
🗂️ Analyse auto du dossier téléphone (WhatsApp + contacts)
Scanne récursivement un dossier d'extraction (ou un dossier Android/data) : trouve msgstore.db, wa.db (contacts WhatsApp) et les fichiers .crypt14/.crypt15, puis décode automatiquement les messages avec les noms de contacts joints.
