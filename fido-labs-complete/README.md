# FIDO-LABS v1.0 - Extracteur Carte Memoire + Disque Externe + Analyseur Mobile
Langage: Rust + Tauri (plus rapide que MOBILedit)
Auteur: Pour investigateur numérique local - Usage légal uniquement avec autorisation

## Lancer l'interface
Ouvrir index.html dans navigateur pour voir UI Pro Blanche

## Lancer le projet Rust
cd src-tauri
cargo tauri dev

## 3 Extracteurs
- Mobile: Android (Tecno, Infinix, Samsung, MTK, Qualcomm) / iOS
- SD Card: FAT32/exFAT carving
- Disk: HDD externe NTFS/exFAT -> Image E01/DD avec hash

## Analyseur
- Super Timeline, Money Flow Orange/ Moov/ Wave, Link Graph, YARA search

⚠️ ETHIQUE: Ce squelette ne contient AUCUN exploit de contournement de verrou. L'extraction sur téléphone verrouillé nécessite code propriétaire ou mandat + outil certifié. FIDO-LABS loggue tout.
